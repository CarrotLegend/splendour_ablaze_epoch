## 五类清单

- 已恢复：反重力装置、两种石柱、湿白砖、辉光石灰岩及已注册关联矿石的褪色回调、韭葱、小米、七种原版树苗、斑竹芽与茎、绒羽泡沫、桑叶与山楂叶结果、梧桐、桂花和木槿焰叶定时粒子、原版指定叶片及草本的剪取回调、白茅邻水放置。

- 部分恢复：三种蚕架保留现有服务端防复制逻辑；随机抽取茧数的细节与原版逐次重抽写法存在差异。梧桐第二粒子的资源 ID 使用现有带下划线名称。
- 依赖未注册：`suspiciousradiantlimestoneleadore`、纸茧所需 `pagewraith` / `pagegnat` 等实体。
- 原版无额外行为：`InkgrassblockwitheredProcedure` 在本 JAR 中没有方块调用入口；普通装饰石材、木材和储物容器的阶段外回调不在本阶段接入。
